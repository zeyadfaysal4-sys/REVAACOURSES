# REVAACOURSES

REVAACOURSES is a full-stack online learning platform that allows users to browse and explore educational courses across different categories.

## Project Overview

The platform provides an easy and responsive experience for users to discover courses, view course details, and filter courses based on different criteria.

The project also includes an Admin Dashboard for managing courses and categories.

## Features

- Browse available courses
- View course details
- Course categories
- Filter courses by:
  - Title
  - Price
  - Date
  - Category
- Pagination
- Course images
- Responsive user interface
- Admin Dashboard
- Course management
- Category management

## Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML5
- CSS3
- Bootstrap
- Razor Views
- JavaScript
- Git & GitHub

## Architecture

The project is built using the MVC (Model-View-Controller) architectural pattern.

### Models

Responsible for representing the application's data and database entities.

### Views

Built using Razor Views, HTML, CSS, and Bootstrap to provide the user interface.

### Controllers

Handle application requests, business logic, filtering, pagination, and communication with the database.

## Course Filtering

Users can filter courses using multiple criteria:

- Course Title
- Course Price
- Creation Date
- Course Category

## Pagination

The platform uses pagination to display courses across multiple pages, providing a better user experience when dealing with a large number of courses.
